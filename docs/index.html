QC_barcode_filter

RNA barcode filtering strategy based on total cell RNA UMI depth.

More contextThe preprocessing script sums RNA UMIs per cell, sorts barcodes from highest to lowest total_gene_umis, plots log1p(total_gene_umis) versus barcode rank, and estimates up to two knees. 'knee' uses the first/basic knee: the barcode-rank point with maximum distance from the line joining the highest-UMI and lowest-UMI barcodes. This is more permissive and keeps cells with total_gene_umis greater than or equal to the UMI count at that first knee. 'knee2' first restricts the curve to the high-UMI segment before knee1 and then finds a second/advanced knee using spline curvature; this is stricter and is intended to remove additional low-quality or background barcodes inside the initially retained population. 'none' disables UMI-knee filtering and instead applies QC_min_genes_per_cell. If the requested knee cannot be determined, barcode filtering is skipped with a log message; preprocessing then continues, and because QC_barcode_filter is not 'none', the min-genes cell filter is also skipped. Cells tied at the selected UMI threshold are retained.
string'knee2'none, knee, knee2
