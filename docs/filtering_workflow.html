Physical concatenation All three batch matrices are combined independently for each modality.
First MuData mudata.h5mu aligns the concatenated modalities by shared cell barcode.
Guide assignment Runs separately after the MuData is split back into batches.
Final MuData concat_mudata.h5mu is the inference input.
Batch grouping rule: the pipeline key is sample_${file_modality}_${measurement_sets}, not the FASTQ filename or the empty lane field. The two guide rows for each Gary Hon measurement set therefore enter the same mapping job. After mapping, every cell barcode is qualified with its measurement set before modality concatenation.
Audit of the completed May 14, 2026 run: that checkout used positional suffixes _0, _1, and _2. Its RNA, guide, and hashing concatenation logs all used the identical order 6244, 8721, 9613, so its intersections were same-batch. The updated implementation uses the explicit measurement-set ID instead, removing the ordering dependency.

Same-batch matching example: AAAC..._IGVFDS6244NAXC in RNA can only match the same qualified key in hashing and guide data. A raw AAAC... barcode from IGVFDS8721BKRO has a different key.
No fixed guide-UMI cutoff is applied before MuData creation. The raw per-cell guide count matrix is aligned with RNA cells first. SCEPTRE or CLEANSER then converts guide counts into the binary guide_assignment layer.

Main filter points in code

Snippets are shortened for readability but preserve the operative conditions and expressions from the repository.

0. Group FASTQs into batch mapping jobs

The grouping key is modality plus measurement_sets.

subworkflows/local/utils_nfcore_crispr_pipeline/main.nf 
def meta = [
    id: "sample_${row.file_modality}_${row.measurement_sets}",
    modality: row.file_modality,
    measurement_sets: row.measurement_sets,
    lane: row.lane
]

[meta.id, meta, [r1_path, r2_path]]
    .groupTuple()
    .map { meta, fastqs ->
        [meta, fastqs.flatten()]
    }

// Gary Hon: two guide rows share each measurement_sets value.
// Their two R1/R2 pairs are pooled into one guide mapping job.

3. RNA gene and mitochondrial filters

The minimum-gene cell filter is mutually exclusive with knee filtering.

4. Hashing follows RNA QC

Hashing barcodes are restricted to cells surviving RNA filters.

bin/filter_hashing.py 
hashing = ad.read_h5ad(hash_file)
filtered_rna = ad.read_h5ad(filtered_rna_file)

intersecting_barcodes = list(
    set(hashing.obs_names).intersection(
        filtered_rna.obs_names
    )
)

hashing_filtered = hashing[intersecting_barcodes, :]

for batch in hashing_filtered.obs["batch"].unique():
    adata_subset = hashing_filtered[
        hashing_filtered.obs["batch"] == batch
    ].copy()
